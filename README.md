# Training Camp Argentina 2025

Files and resources from the competitive programming training camp hosted at UTN Santa Fe (July 2025).

## About

Intensive training for ICPC-style competitions. Topics covered: dynamic programming, advanced data structures, graph algorithms and problem-solving under pressure.

**Participants (beginner level):** Gino Rubén Giorgi · Juan Manuel García

## Contents

Practice problems, solutions and notes from the training sessions.
